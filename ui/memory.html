How scoring works

score = .50·semantic cosine
      + .25·FTS5/BM25 keyword
      + .15·importance + .10·access
      +  .3 pinned boost
decay   30-day half-life (pins bypass)

This is fully local: FTS5 + cosine over stored 384-dim embeddings. The sleep/consolidation job is planned, not active by default. Tool calls that create candidates should create proposals, not silent writes.
